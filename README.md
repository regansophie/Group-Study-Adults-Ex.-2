# Group Study Adults Experiment 2

This repository contains the jsPsych web version of Experiment 2.

To run a specific counterbalance version, add `?version=1` through `?version=8`
to the page URL. Participant IDs can be passed with `?participant=...` or the
standard Prolific URL parameters.

Data are saved through DataPipe using experiment ID `aZEUjZ2GD7ys`.
